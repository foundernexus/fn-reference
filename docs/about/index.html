About

What Founder Decisions is, who it is for, and how numbers are sourced.

Founder Decisions is a set of independent decision pages for venture-scale and venture-backed founders. Each page is meant to fully answer one search: the table, the range, the tradeoff. You should be able to use it without joining anything.

It is for founders writing the grant, the hire, or the board paper. Seed through Series B, building toward venture scale.

Numbers come from named public sources. Ranges are not invented. If a source did not publish a figure, the cell is empty. When sources disagree, they are shown separately rather than averaged.

Not legal, tax, or compensation advice.
