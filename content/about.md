Founder Decisions is a set of decision pages for venture-scale and venture-backed founders. Each page is meant to fully answer one search: the table, the range, the tradeoff. You should be able to use it without applying to anything.

It is for founders writing the grant, the hire, or the board paper. Seed through Series B, building toward venture scale.

Numbers come from named public sources. We do not invent ranges. If a source did not publish a figure, the cell is empty. When sources disagree, we show them separately rather than averaging.

FounderNexus publishes Founder Decisions. It is not legal, tax, or compensation advice.
